Hướng Dẫn Cấu Hình Thiết Bị Ronald Jack 009 Thực Tế:

1. Cài đặt IP trên máy Ronald Jack:

Vào Menu máy → Thiết lập liên kết → Mạng Ethernet → Đặt IP tĩnh (Ví dụ: 192.168.1.201), Netmask: 255.255.255.0, Gateway: 192.168.1.1.

2. Cổng giao tiếp & Mật mã kết nối:

Port mặc định của ZKProtocol: 5005 (hoặc 5006, 5007). Mục Comm Key đặt bằng 0 (mặc định không đổi mật khẩu).

3. Đăng ký vân tay & Mã nhân viên:

Mã ID nhân viên đăng ký trên máy Ronald Jack (ví dụ: 1001) phải trùng khớp với cột Mã chấm công (attendance_code) trong Hồ Sơ Nhân Sự.

Kịch Bản Tự Động Hóa Agent (Background Auto-Sync Service)

Giải pháp chuyên nghiệp dành cho doanh nghiệp: Chạy ngầm định kỳ 5 - 10 phút trên Windows Task Scheduler của máy chủ/PC cài Ronald Jack Pro.

1 Tải script về máy tính

Bấm nút "Tải Bộ Cài Agent" để tải file ronald_jack_agent.ps1 và install_agent_task.bat về thư mục trên máy cài Ronald Jack Pro.

2 Kiểm tra cấu hình CSDL

Mở file agent_config.json để kiểm tra tên database SQL Server (mặc định: RonaldJackPro) hoặc đường dẫn Access att2000.mdb.

3 Kích hoạt tự động hóa

Click chuột phải vào install_agent_task.bat chọn "Run as administrator". Windows Task Scheduler sẽ tự động đồng bộ ngầm mỗi 5 phút!

Mã lệnh Agent PowerShell tự động (scripts/ronald_jack_agent.ps1):
# Đọc các lượt quẹt thẻ mới từ CSDL Mitaco / Ronald Jack Pro (113.161.53.133,1433)
$query = "SELECT c.ID, c.MaChamCong, nv.MaNhanVien, nv.TenNhanVien, c.GioCham, c.TenMay FROM CheckInOut c LEFT JOIN NHANVIEN nv ON c.MaChamCong = nv.MaChamCong WHERE c.GioCham >= @LastSyncTime"
# Gửi dữ liệu quẹt thẻ mới lên API Trung Hải HRM
$res = Invoke-RestMethod -Uri "https://trunghaico.vn/api/attendance/zk/software-sync" -Method Post -ContentType "application/json" -Body (@{ db_type="sql_server"; server_host="113.161.53.133"; database_name="mitaco"; punch_logs=$punches } | ConvertTo-Json)
Write-Host "Đã đồng bộ thành công: $($res.added_count) bản ghi quẹt thẻ mới từ CSDL Mitaco."
